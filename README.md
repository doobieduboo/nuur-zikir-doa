# Nuur — Zikir & Doa Setelah Salat

Web App (PWA) pribadi berbahasa Indonesia dengan penghitung zikir, panduan Arab/Latin, mode doa, pengaturan tampilan, dan data lokal.

## GitHub Pages

Atur **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**.

Akses: https://doobieduboo.github.io/nuur-zikir-doa/

Buka dengan Chrome Android melalui HTTPS kemudian pilih **Tambahkan ke layar utama / Instal aplikasi** jika tersedia. Setelah pertama kali dimuat dengan internet, cache mendukung penggunaan offline.

Teks doa permohonan adalah susunan pribadi, bukan lafaz hadis. Progres zikir hanya disimpan di browser perangkat, bukan di GitHub.
